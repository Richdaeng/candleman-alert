# 캔들맨 알림 (candleman-alert)

바이낸스 USDⓈ-M 선물과 현물에서 내 **주문 · 체결 · 청산(매도)**을 실시간으로 받아 내 디스코드 서버에 올리고,
매일 **오후 10시(한국 시간)**에 하루 요약을 올리는 작은 프로그램입니다. 갤럭시 폰의 Termux에서 돌리도록 만들었습니다.

## 무엇을 올리나

`#실시간-매매`

투자를 모르는 사람도 읽게 씁니다. 첫 줄에 무슨 일인지(종목 이름 · 롱/숏 풀이 · 이익/손실), 둘째 줄에 가격 · 수량.
디스코드에는 첫 줄이 머리 줄(폰 알림에 보이는 줄 · 굵은 글씨 없음)로, 나머지가 색 띠 카드 안에 한 줄에 한 가지(금액 · %는 굵게)로 올라갑니다
(`candleman/cards.py` — 롱 진입 · 추가 초록, 숏 빨강, 일부 정리 주황, 모두 정리 · 취소 회색, 강제 청산 진한 빨강, 주문 걸어 둠 파랑, 현물 매수 노랑).
`#봇-상태`도 여러 줄 소식은 같은 모양입니다. 아래 예시는 보내기 전 줄글입니다.

```
📝 주문 걸어 둠 · 비트코인(BTC) 롱 진입 (오르면 이익)
$82,000에 0.05 BTC · 약 $4,100어치(레버리지 포함) · 아직 체결 전

🟢 비트코인(BTC) 롱 진입 · 오르면 이익
$82,000에 0.05 BTC · 약 $4,100어치(레버리지 포함) · 걸어 둔 주문 체결

➕ 비트코인(BTC) 롱 추가 진입 · 오르면 이익
$81,500에 0.03 BTC 더 · 평균 가격 $81,812.50 · 모두 0.08 BTC · 약 $6,545어치(레버리지 포함) · 바로 체결(시장가)

📝 스탑 로스 걸어 둠 · 비트코인(BTC) 롱 청산
가격이 $80,000에 닿으면 시장가로 모두 정리 · 아직 발동 전

🟠 비트코인(BTC) 롱 일부 청산 · 이익 +$47.50
$83,000에 0.04 BTC 정리 · 남은 0.04 BTC · 바로 체결(시장가)

✖️ 주문 취소 · 비트코인(BTC) 롱 청산 · $84,000에 0.04 BTC

⬜ 비트코인(BTC) 롱 청산 · 이익 +$67.50
$83,500에 남은 0.04 BTC 모두 정리 · 1시간 12분 보유 · 바로 체결(시장가)
이번 거래 전체 이익 +$115.00

🔴 한국 주식 ETF(EWY) 숏 진입 · 내리면 이익
$154.90에 20주 · 약 $3,098어치(레버리지 포함) · 바로 체결(시장가)
```

- 미체결 주문(지정가 · 스탑 로스 · 익절 · 트레일링 스탑)은 넣은 지 2초 뒤에 알립니다. 2초 안에 바로 체결되면 '주문' 글은 건너뛰고 체결만 알립니다.
- 시장가 주문은 체결만 알립니다. 부분 체결은 5초씩 모아서 알립니다.
- 걸어 둔 스탑 · 익절 주문이 발동해 체결되면 끝에 '스탑 로스 발동' · '이익 보전 스탑 발동' · '익절 주문 발동'을 붙입니다. 바이낸스는 발동하면 원래 종류
  없이 새 시장가 주문을 만들어서, 발동 소식(앞뒤 30초 · 같은 종목 · 같은 방향, 실제 주문 번호를 알면 그 번호)과 짝지어 가립니다(10/22 고침 — 전에는 '바로 체결(시장가)').
- 포지션을 닫는 스탑은 발동 가격이 평균 진입가와 같거나 유리한 쪽(롱은 위 · 숏은 아래)이면 '이익 보전 스탑', 아니면 '스탑 로스'라고 부릅니다.
  발동해 체결된 글은 실제 손익으로 다시 가립니다(이익이면 이익 보전 스탑) — 10/22 댕이: "스탑로스인데 익절일 수도 있잖아?"
- 취소 · 만료는 '주문' 글이 먼저 올라간 주문만 알립니다. 포지션을 다 정리해서 바이낸스가 저절로 지우는 스탑 로스 · 익절은 알리지 않습니다.
- '약 …어치'는 레버리지까지 친 포지션 크기라 실제로 넣은 돈은 이보다 적다는 걸 글에 같이 적습니다.
- 이익 · 손실은 바이낸스가 주는 실현 손익 그대로라 수수료가 빠지지 않은 금액입니다(수수료 · 펀딩비는 하루 요약에 따로).
- 종목 이름은 `candleman/names.py` 에 있는 것만 풀어 씁니다(없으면 기호 그대로). 주식 · ETF 는 수량을 '주'로 적습니다.
- 강제 청산은 ⚠️ 로 따로 알립니다. 수익률(%)은 넣지 않습니다. 휴대폰 알림에 별표가 그대로 보여서 굵은 글씨는 쓰지 않습니다.

현물도 같은 채널에 같은 약속으로 올립니다(`SPOT=0` 이면 끔).

```
🟢 비트코인(BTC) 현물 매수
$82,000.00에 0.05 BTC · 약 $4,100어치 · 바로 체결(시장가)

➕ 비트코인(BTC) 현물 추가 매수
$82,000.00에 0.05 BTC 더 · 모두 0.15 BTC · 약 $4,100어치 · 걸어 둔 주문 체결

🟠 비트코인(BTC) 현물 일부 매도 · 이익 +$36.68
$83,000.00에 0.04 BTC 정리 · 남은 0.06 BTC · 약 $3,320어치 · 바로 체결(시장가)

⬜ 비트코인(BTC) 현물 모두 매도 · 손실 −$12.30
…
```

- 현물 손익은 바이낸스가 주지 않아서, 그 코인 · 달러 짝(예: BTCUSDT)의 내 거래 기록을 처음부터 이어 평균 매수가(이동 평균, 수수료 포함)를 계산해
  `판 금액 − 수수료 − 평균 매수가 × 판 수량`으로 셉니다. 입금하거나 다른 짝으로 산 몫까지 팔면 '산 값을 몰라 손익은 뺌'으로 적습니다.
- 현물 실시간 자료는 WebSocket API(`wss://ws-api.binance.com:443/ws-api/v3`)에 서명으로 구독합니다(`userDataStream.subscribe.signature` · 현물 listenKey 는 2026년에 없어짐).
  끊겼던 사이의 현물 체결은 따로 알리지 않고, 손익 장부는 다음에 거래 기록으로 이어 맞춥니다.
- 매일 요약(`#일일-요약`)에도 현물을 넣습니다: 거래 횟수 · 실현 손익 · 미실현 손익 · 수수료 아래 `└` 줄에 선물 · 현물을 나눠 적고, 현물 보유도 포지션 카드에 넣습니다.
  현물 손익 · 수수료는 체결 때 이 프로그램이 셈해 둔 일지로 세므로, 프로그램이 꺼져 있던 동안의 현물 거래는 빠질 수 있습니다(카드 아래 작은 글씨로 알림).

`#일일-요약` (매일 22시, 전날 22시 ~ 오늘 22시) — 머리 한 줄 + 카드 두 장. 손익 카드 띠는 실현 손익 + 수수료 + 펀딩비가 이익이면 초록 · 손실이면 빨강.

```
📒 10/21 (수) 하루 요약 · 10/20 22:00 ~ 10/21 22:00
┃ 💵 하루 손익
┃ 거래 4번 (선물 1번 · 현물 3번)
┃ 실현 손익 +$259.08
┃ └ 선물 +$212.40 · 현물 +$46.68
┃ 미실현 손익 +$48.00
┃ └ 선물 −$12.00 · 현물 +$60.00
┃ 수수료 −$13.33
┃ └ 선물 −$8.10 · 현물 −$5.23
┃ 펀딩비 −$1.20
┃ 📌 들고 있는 포지션
┃ 🟢 솔라나(SOL) 롱 · 12 SOL
┃ └ 평균 가격 $150.25 · 약 $1,803어치(레버리지 포함) · 미실현 −$12.00
┃ 🪙 비트코인(BTC) 현물 · 0.06 BTC
┃ └ 평균 매수가 $82,000.00 · 약 $4,980어치 · 미실현 +$60.00
```

`#봇-상태` (나만 보는 채널): 시작 · 다시 연결 · 마진 콜 같은 소식.

`#종목설명` (선택): 처음 진입한 종목을 한 번씩 소개합니다(`candleman/names.py` 의 설명 · 없으면 바이낸스 분류로 한 줄 + `#봇-상태`에 '설명 추가 필요').
`DISCORD_WEBHOOK_SYMBOLS` 를 넣었을 때만 켜지고, 이미 공지에 있는 BTC · ETH · SOL · EWY · SKHY 는 다시 소개하지 않습니다.

`#현재포지션` (선택): 포지션이 바뀔 때마다 지금 포지션을 `/포지션`과 같은 카드로 새 글로 올립니다. 지난 글과 같으면 올리지 않습니다.
- 거래 뒤: 체결로 종목 · 방향 · 수량이 바뀌면 (나뉘어 들어와도 3초 조용해진 뒤 한 번만).
- 다시 켤 때 · 끊겼다 붙을 때 · 10분마다(놓친 체결 · 입금 · 출금 대비): 선물 포지션이 다르거나, 현물 코인 수량이 1% 넘게 · $10 어치 넘게
  바뀌었을 때만. 지갑끼리 옮긴 것(지갑은 합쳐 셈) · Earn 이자 · 찌꺼기로는 올리지 않습니다 — 10/22 06:30 에 솔라나가 현물 지갑에서
  빠져 거래 없이 글이 올라간 뒤에 바꿈.

현물은 달러 코인(USDT · USDC 등)을 뺀 $10 이상인 코인만 노란 카드(🪙)로 — 수량 · 평균 매수가 · 지금 가격 · 평가 금액 · 미실현 손익(평균 매수가를 알 때만).
현물 지갑 · Earn(자유 · 기간 고정 예치) · 펀딩 지갑 · 선물 지갑(수수료용 BNB 등)을 코인마다 합쳐 셉니다. 현물 지갑 밖에 있으면
'보관 Earn 예치'처럼 둔 곳을 한 줄 붙입니다(여러 곳이면 '현물 지갑 1 SOL + Earn 예치 26.7 SOL'). 키 권한 등으로 거절된 지갑은
그 실행 동안 빼고 보여 줍니다(`data/app.log` 에 한 줄). `DISCORD_WEBHOOK_POSITIONS` 를 넣었을 때만 켜집니다(`python -m candleman hook positions`).

**주인장 수익률**: 선물 포지션을 끝까지 정리하거나 방향을 바꿀 때, 현물 코인을 모두 팔 때 `#실시간-매매`에 한 번 붙입니다
(정리 알림 3초 뒤 · `#잡담방`의 `/주인장수익률`도 같은 글).

```
📊 2026 주인장 수익률 · 10/21 20:00 기준
시작: $7,800.00
현재: $8,123.45
수익률: +4.15% (+$323.45)
```

- 해마다 따로 셉니다. `START_YEAR`(기본 2026)까지의 시작 = `START_USD`(기본 7800 — 10/21 댕이가 $7,800 으로 시작),
  그다음 해부터는 그해 1월 1일 0시(한국 시간)에 폰이 읽은 바이낸스 전체 자산이 시작입니다(`data/state.json` 의 `year_start` · 잡을 때 `#봇-상태`에 남김).
  그 시각에 프로그램이 꺼져 있었으면 다시 켜진 때 값으로 잡고 그렇다고 적습니다. `START_USD=0` 이면 이 글과 `/주인장수익률`이 꺼집니다.
- 현재 = 선물 지갑(자산마다 지갑 잔고 + 미실현 손익 · 수수료용 BNB 같은 코인도) + 현물 지갑 + Earn(자유 · 기간 고정 예치) + 펀딩 지갑을
  달러로 합친 값. 코인은 USDT 짝 시세로 매기고, 현물 쪽은 `#현재포지션`과 같은 방법으로 읽습니다. 코인 선물(COIN-M) · 마진 · 트레이딩 봇 지갑은 넣지 않습니다.
- 입금 · 출금을 하면 그만큼 수익률이 틀어지니 그해 기준을 고쳐 주세요(`START_YEAR=그해` + `START_USD=새 기준` — 정해 둔 금액이 1월 1일 값보다 먼저 씀).

`#일일-경제-브리핑` (선택): 매일 08시(한국 시간)에 아침 경제 브리핑을 카드로 올립니다.

```
🗞️ 10/22 (목) 아침 경제 브리핑
┃ 💳 신용 · 미수 잔고 (10/20 화 기준)
┃ 신용융자 30.51조 원 (−5,944억) · 미수금 1.19조 원 (−2,418억)
┃ 반대매매 227억 원 (미수금의 1.6%) · 투자자예탁금 90.30조 원 (−1.80조)
┃ 🌙 밤사이  · 미국 증시 … · 비트코인 …
┃ 📅 다가오는 일정 · 중요도 5점 만점
┃ ★★☆☆☆ 2점 · 10/22 (목) 한국은행 금통위
┃ ★★★★☆ 4점 · 10/28 (수) 미국 FOMC 기준금리 결정
┃ ★★★★★ 5점 · 11/03 (화) 미국 중간선거
┃ ★ 중요도 = 2016~2026년 같은 일정 날 주가 · 코인 · 금리가 평소보다 크게 움직인 정도
```

- 일정의 중요도(1~5)는 2016~2026년 시세로 잰 표를 따라 클라우드 작업이 매기고(`impact`), 폰이 별(★)로 그립니다.
  잰 방법: 그 일정이 있던 날의 하루 움직임 크기를 같은 요일의 평소 날과 견줌(다른 일정과 겹친 날은 뺌 · 평소 날을 무작위로 5,000번 뽑아 우연인지 확인).
  5점 미국 대선 · 중간선거(미국 주식 평소의 2.9배) · 4점 미국 고용 · CPI · FOMC · 빅테크 실적(1.3~1.45배) · 3점 엔비디아 실적(SK하이닉스 1.4배)
  · 2점 PCE · GDP 속보치 · 금통위(평소와 뚜렷한 차이 없음) · 1점 작은 지표. 이번에 결과 예상이 크게 갈리면 1점을 더합니다.
  점수가 없거나 1~5가 아니면 별 없이 적고, 별이 있을 때만 카드 아래에 별의 뜻을 한 줄 적습니다.

- 숫자는 이 폰이 금융투자협회 종합통계(공개 자료)에서 직접 받습니다. 협회는 전날 수치를 다음 영업일에 올려서 카드 제목에 기준일을 적습니다.
- 밤사이 소식 · 다가오는 일정은 Claude 클라우드 예약 작업(Opus 5.5 · 추론 강도 max)이 매일 06:00에 웹에서 찾아
  브리핑 전용 저장소 [candleman-briefing](https://github.com/Richdaeng/candleman-briefing)의 `main`에 `briefing.json`
  (`{"date": "YYYY-MM-DD", "overnight": [...], "schedule": [{"when", "what", "impact", "why"}]}`)으로 올려 둔 것을 가져옵니다. 오늘 날짜가 아니면 쓰지 않고,
  줄 수 · 길이를 잘라 짧게 유지합니다. 08:20까지 오지 않으면 숫자만 올리고 `#봇-상태`에 알립니다.
- 예약 작업에 GitHub 쓰기 권한을 주는 곳은 그 브리핑 저장소뿐입니다. 이 저장소(폰이 매일 05시에 `stable`을 받아 실행하는 코드)에는 쓰지 못하게 따로 뒀습니다.
- `DISCORD_WEBHOOK_BRIEFING` 를 넣었을 때만 켜집니다(`python -m candleman hook briefing`). 시각은 `BRIEFING_HOUR`, 바로 시험은 `python -m candleman briefing`.

글쓴이 이름 · 사진은 프로그램이 정하지 않고 디스코드의 웹후크 설정을 따릅니다(채널 설정 → 연동 → 웹후크에서 바꾸면 바로 반영).

## 안전하게 만든 점

- **들어오는 문이 없음**: 바이낸스와 디스코드로 *나가는* 연결만 합니다. 서버를 열지 않아 밖에서 이 폰에 접속할 길이 없습니다.
- **받은 내용을 실행하지 않음**: 바이낸스의 체결 정보에서 숫자만 읽습니다. 디스코드에서는 글을 보내기만 하고 읽지 않습니다.
- **바깥 부품 0개**: 파이썬 기본 기능만 씁니다(실시간 연결도 직접 구현). 남이 만든 부품이 섞일 일이 없습니다.
- **읽기 전용 키**: 주문 · 출금 함수는 일부러 만들지 않았고, `check` 명령이 키에 거래 · 출금 권한이 켜져 있으면 경고합니다.
- **키는 폰에만**: `.env` 파일(나만 읽기 권한)에만 저장합니다. 저장소 · 기록 · 디스코드 글에는 넣지 않습니다.
- **Termux 권한 0개**: 저장공간 · 연락처 · 문자 · 위치 권한이 필요 없습니다. 물어보면 주지 마세요.
- **자동 업데이트는 `stable` 만**: 매일 05시에 시험을 통과한 판(`stable` 가지)만, 앞으로 이어질 때만, 폰에서 시험을 다시 통과해야 바꿉니다. 끌 수 있음(`AUTO_UPDATE=0`). 아래 '업데이트'.

## 폰에 설치 (갤럭시 · Termux 플레이 스토어 판)

1. 플레이 스토어에서 **Termux**를 설치하고 한 번 엽니다 (처음 준비가 끝날 때까지 기다림).
2. 설정 → 애플리케이션 → Termux → 배터리 → **제한 없음**.
3. Termux에 붙여 넣기:

```
pkg install -y git && git clone https://github.com/Richdaeng/candleman-alert ~/candleman-alert
bash ~/candleman-alert/termux/install.sh
```

4. 설정과 시험:

```
cd ~/candleman-alert
python -m candleman setup
python -m candleman check
./termux/start.sh
```

`setup` 은 질문에 답하면 `.env` 를 만듭니다(비밀키는 화면에 안 보임). `check` 는 키 권한을 확인하고 `#봇-상태`에 시험 글을 보냅니다.
폰을 다시 켜면 30초 뒤 자동으로 시작합니다(`~/.termux/boot/boot-candleman.sh`).

## /포지션 · /주인장수익률 명령 봇 (선택)

`#잡담방`에서 `/포지션`을 치면 운영자가 지금 들고 있는 포지션을, `/주인장수익률`을 치면 시작 금액 대비 지금 자산과 수익률(위 '주인장 수익률'과 같은 글)을
모두에게 보이게 답합니다. 웹후크와 따로 '디스코드 봇'이 하나 필요합니다. 새 명령은 봇이 다시 켜질 때 저절로 등록됩니다.

답은 종목마다 카드 한 장(롱은 초록 · 숏은 빨강 띠)이고, 한 줄에 한 가지씩 보입니다: 수량 · 평균 가격 · 지금 가격 · 거래 크기 · 실제 레버리지 · 미실현 손익.
금액은 소수 둘째 자리까지($1 보다 싼 가격만 유효숫자 네 자리). 실제 레버리지 = 거래 크기 ÷ 증거금
(교차 마진은 계좌 전체 증거금, 격리 마진은 그 포지션에 넣은 증거금) — 바이낸스에 정해 둔 배율(예: 20배)이 아니라 실제로 쓰고 있는 배율입니다.
증거금 금액 자체는 보이지 않습니다.

1. https://discord.com/developers/applications → **New Application** → 이름(예: 매매일지봇) → 만들기
2. **Bot** 메뉴 → **Reset Token** → 토큰 복사(한 번만 보임). **Public Bot** 은 끄고, Privileged Gateway Intents 는 **Message Content Intent** 하나만 켭니다
   (아래 커뮤니티 기능의 '같은 말 도배' 감지용 · 안 켜도 나머지는 됨).
3. **OAuth2 → URL Generator** → Scopes 에서 `bot` · `applications.commands` 만 고르고, Bot Permissions 는 아무것도 고르지 않습니다 → 맨 아래 주소를 열어 서버를 고르고 승인
4. 폰에서 `python -m candleman bot` → 토큰 붙여 넣기(안 보임) → `python -m candleman check` → `./termux/stop.sh` → `./termux/start.sh`
5. `#잡담방`에서 `/포지션`

- 봇도 폰에서 디스코드로 *나가는* 연결만 씁니다. 받은 것에서는 명령 이름 · 채널 · 부른 사람만 보고 아무것도 실행하지 않습니다.
- 명령에 답하는 데는 서버 권한이 필요 없습니다. 아래 커뮤니티 기능(입장 · 레벨 · 도배)에만 `🤖 봇` 역할의 권한 네 가지가 필요합니다. 토큰은 `.env` 에만 둡니다.
- 바이낸스에는 30초에 한 번까지만 묻고, 같은 사람이 너무 자주 부르면 한동안 막은 뒤 `#봇-상태`에 알립니다(서버 주인만 예외 · 관리자 역할을 받은 사람도 막힘).
- 다른 채널에서 부르면 부른 사람에게만 '#잡담방에서 쓸 수 있음'이 보입니다. 채널을 바꾸려면 `.env` 에 `DISCORD_COMMAND_CHANNEL=채널이름`.

### /일지 — 거래한 이유 남기기 (운영자 전용)

진입 · 추가 · 정리할 때 왜 했는지를 남겨 두면, 나중에 체결 기록과 맞춰 "이유별 · 확신별로 어느 쪽이 벌었나"를 셀 수 있습니다
(10/22 댕이: "내 데이터를 모아서 개선할 수 있는 방법").

```
/일지 이유:거시 경제 때:진입 확신:4 종목:EWY 손절가:150 목표가:165 메모:FOMC 앞 매수
```

- 꼭 고르는 것: 이유(거시 경제 · 뉴스 · 일정 · 차트 · 직감 · 기타) · 때(무엇을 했나 — 진입 · 추가 · 정리(손으로) · 스탑(걸기 · 옮기기) · 목표(익절 주문 걸기)).
  손절인지 익절인지는 결과라서 고르지 않고, 나중에 체결 기록의 손익으로 붙입니다. 10/22 '때'를 비워 스탑 얘기가 '진입'으로 남은 뒤로 꼭 고르게 바꿈.
- 골라서 넣는 것: 확신(1 ~ 5) · 종목(비우면 최근 7일 안에 마지막으로 주문 · 체결된 종목) · 손절가 · 목표가 · 메모(300자까지).
- 서버 주인만 쓸 수 있고 다른 사람에게는 명령 목록에도 안 보입니다. 어느 채널에서 써도 확인 답은 쓴 사람에게만 보입니다(`#매매일지`에서 쓰는 것을 권함).
- 남긴 것은 폰의 일지(`data/journal.jsonl`, `"kind": "note"`)와 `#매매일지`에 카드 한 장씩 남습니다. 고치려면 한 번 더 쓰면 됩니다(나중 것을 씀).
- `#매매일지`는 모두 볼 수 있고 글은 운영자만 쓰는 채널입니다(10/22 댕이 · `#실시간-매매`를 복제해 만듦 — 메시지 보내기 · 스레드 막힘).
  웹후크를 넣습니다: `python -m candleman hook journal` → 다시 켜기. 웹후크를 안 넣으면 나만 보는 `#봇-상태`에 남깁니다.

### 커뮤니티 — #규칙 입장 · 레벨 · 도배 처리 (2026-10-26)

5초 안에 5개 이상)". 같은 봇이 하고(코드는 `candleman/community.py`), `.env` 에 `COMMUNITY=0` 이면 끕니다.

  서버 주인은 레벨 역할을 바꾸지 않습니다(👑 운영자로 보임).

(없애려면 `#규칙` 채널 권한에 `🤖 봇` 추가 → 메시지 보내기 ✓ → 다시 `/규칙올리기` — 전 글은 저절로 지움).
글 내용 받기(Message Content Intent)가 거절돼 내용 없이 붙었으면, 6시간 뒤 봇이 스스로 다시 붙어 한 번 더 시도합니다.


같은 확인 · 시험을 거친 뒤 다시 켜고, 1분쯤 뒤 `#봇-상태`에 결과가 옵니다. Termux 의 wake lock 은 건드리지 않습니다.
새 판에 서버 사람들에게 알릴 것이 있으면 처음 켤 때 `#실시간-매매` · `#일일-요약`에 안내 글이 한 번만 올라갑니다(`candleman/notices.py`).

자동 업데이트가 없던 옛 설치는 처음 한 번만:

```
cd ~/candleman-alert && git -c core.fileMode=false pull && bash termux/restart.sh
```

`-c core.fileMode=false` 는 설치 때 준 실행 권한(chmod) 차이 때문에 `git pull` 이 멈추지 않게 하는 것입니다.

## 알림이 안 올 때

1. `./termux/status.sh` 로 돌고 있는지 확인합니다.
2. 배터리가 **제한 없음**인지, Termux 알림 표시줄에 'wake lock' 이 보이는지 확인합니다.
3. `python -m candleman check` 로 키 · 웹후크를 다시 시험합니다. 디스코드에서 웹후크를 지웠다면 새로 만들어 `setup` 을 다시 합니다.
4. 연결이 끊겼다 붙으면 `#봇-상태`에 알리고, 그사이 바뀐 포지션은 `#실시간-매매`에 한 번에 알립니다.

## 지우기

```
cd ~/candleman-alert && ./termux/stop.sh
rm -rf ~/candleman-alert ~/.termux/boot/boot-candleman.sh
```

그리고 바이낸스에서 API 키를, 디스코드에서 웹후크를 지웁니다.
